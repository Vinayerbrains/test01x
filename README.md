# VisionX Smart Glasses

A single-page, premium e-commerce landing page for VisionX smart glasses.

## Project Structure

```
├── index.html          – Main HTML page
├── styles.css          – Custom CSS (Tailwind + custom utilities)
├── script.js           – Interactivity (smooth scrolling, gallery, modal, loader)
└── greet.py            – Simple CLI greeter (utility)
```

## Features

- **AI Assistant Built-In** – Your intelligent companion, always ready to assist.
- **Real-Time Translation** – Break language barriers effortlessly.
- **Voice Control** – Navigate your world with simple commands.
- **Augmented Reality Display** – Seamlessly blend digital information with reality.
- **HD Camera & Recording** – Capture your moments from a new perspective.
- **All-Day Battery Life** – Power through your day without interruptions.

## Sections

1. **Hero** – Main banner with product image and CTA

## Technologies

- HTML5
- CSS3 (with Tailwind CSS v2.2.19)
- Vanilla JavaScript

## Getting Started

1. Clone the repository
2. Open `index.html` in any modern browser
3. Or serve locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000` in your browser.

## Deployment

1. Commit the files
2. Push to a remote (e.g., GitHub) and serve via GitHub Pages or any static host
